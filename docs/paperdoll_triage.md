Flagged in the paperdoll editor with **N** when no placement could make the art
fit. Almost always the camera angle: warping a 3/4 view onto a front-facing body
is geometrically impossible, so these need redrawing rather than nudging.

See `docs/paperdoll_art_spec.md` for the full recipe. The essentials:
**front-facing, orthographic, lit from top-centre, transparent background**, and
for arms/hands/feet a **matched pair drawn at exactly the same size and angle**.
