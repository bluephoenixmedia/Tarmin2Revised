1Four aesthetic directions — same screen, four skins

What I read from the build

The screenshots show three different visual languages fighting each other: an amber pixel-terminal (workshop, hearth), a painted parchment grimoire (inventory/paperdoll), and an undressed default UI (Shelter Stash Chest). On top of that, the terminal screens have concrete layout faults — tab labels overlap and clip, buttons are truncated mid-word, body copy has no measure limit, right-hand panels sit 80% empty, and every panel is the same flat charcoal so nothing reads as primary.

What each mockup holds constant

  • The same screen — Artisan's Workshop, Forge tab — so you judge only the aesthetic.
  • The same structural fixes: tabs on a real grid, a resource ledger with aligned numerals, a left inventory column with a clear selected state, a right panel that always shows the selected item + its recipe + cost, affordance-aware buttons (affordable vs. blocked), and a persistent key-hint footer.
  • Type floors: no UI text under 13px at this scale, numerals tabular, one column measure for prose.

Pick a direction (or a hybrid — e.g. 1d's layout discipline with 1b's palette) and I'll build the full screen set: HUD, workshop, hearth, inventory, chest, combat overlay.

1aIntellivision Faithful — the real intellivision.ttf, a locked 8-hue palette, 4px hard borders, everything snapped to a chunky grid. Most honest to the Tarmin tribute; least forgiving of dense text.
